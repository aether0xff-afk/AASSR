# AASSR v2

AASSR v2는 기존 구현을 복사하지 않고 처음부터 다시 설계하는 연구용 코드베이스다.

목표는 에이전트에게 정답 행동이나 사물별 규칙을 직접 가르치는 것이 아니다. 다음 세 가지만 가르친 뒤, 최종 목표만 주어진 새로운 환경에서 스스로 유용한 정보를 찾고 행동 조합을 구성하도록 만드는 것이다.

1. 기본 조작 방식: 이동, 관찰, 줍기, 사용, 부수기, 설치하기, 조합하기
2. 일반적인 인과관계: 행동은 상태를 바꾸며, 정보와 물체는 새로운 행동을 가능하게 할 수 있고, 여러 행동은 순서대로 결합될 수 있음
3. 학습 가치 판단: 특정 경험 이후 세계 예측이 실제로 얼마나 개선되었는지를 측정

## 핵심 폐루프

```text
관측
→ Knowledge Store 갱신
→ Policy 상위 행동 선택
→ Prophecy 기반 평행우주 나무 생성
→ 가장 높은 가치의 미래로 이어지는 첫 행동 선택
→ 현실에서 첫 행동만 실행
→ 예측한 다음 상태와 실제 다음 상태 비교
→ Prophecy 및 상상 깊이 교정
→ 다음 상태에서 다시 상상
```

## 평행우주 Imagination

기본적으로 각 우주에서 Policy 상위 `n=2`개 행동을 선택하고, Prophecy가 예측한 다음 상태를 해당 우주의 실제 상태처럼 사용한다. 이 과정을 최대 `k`턴 반복하여 나무를 만든다.

- 각 우주는 독립된 임시 Policy 기억을 가진다.
- 순환형 Prophecy는 우주별 GRU/LSTM 은닉 상태를 가질 수 있다.
- 누적 신뢰도가 낮아지거나 상태가 반복되면 가지를 중단한다.
- 각 깊이에서는 상위 우주만 남겨 계산량 폭발을 막는다.
- 현실 Policy에는 가장 좋은 평행우주로 이어진 첫 행동의 상대 가치만 반영한다.
- 실제 다음 상태만 Prophecy의 학습 근거로 사용한다.

Prophecy의 실제 예측 정확도가 안정적으로 높아지면 상상 깊이를 천천히 늘리고, 정확도가 낮아지면 즉시 줄인다. 자세한 설계는 `docs/imagination_tree.md`에 정리되어 있다.

## 현재 범위: 0.1.0

현재 단계는 새 알고리즘의 성능을 높이는 단계가 아니라, 다음 항목을 정확히 측정할 수 있는 최소 골격을 만드는 단계다.

- 범용 행동 표현
- 상태와 다음 상태 표현
- ASeq 기반 행동-지식 인과 기록
- 같은 행동에 대한 다중 Prophecy 예측
- Imagination 간 불확실성
- Prophecy 예측과 실제 다음 상태의 유사도
- `n=2` 평행우주 Imagination 나무
- 우주별 임시 Policy와 순환 기억 분리
- 신뢰도 기반 가변 상상 깊이
- 정보 가치 점수
- 커리큘럼 단계 정의

기존 AASSR 코드는 이 브랜치에 복사하지 않는다.
