## Audited observation contract

The pentest transfer world uses `response_causal_observation_v3`.

The policy snapshot no longer exposes hidden curriculum level, hidden workflow depth, exact session countdown, audit pressure, or other privileged stage configuration. Workflow progress uses a fixed public scale and `goal_progress` is terminal-only.

`build_pentest_aassr_core()` now enforces that contract and refuses an older pentest snapshot.

## ASEQ self-loop rule

ASEQ is the empirical transition tuple `(S,A,S')`.

The guard suppresses an action only after the same semantic self-loop `S -> A -> S` has actually been observed twice. Repeated state-changing transitions remain allowed. If every available action would be guarded, the raw action set is restored.

The same semantic-state function can now be shared by:

- Policy lookup,
- ASEQ memory,
- Imagination repeated-state detection.

For audited pentest this shared identity is the observation-derived `semantic_fingerprint()`.

## Restored canonical AASSR closed loop

AASSR 0.4 exports:

```python
from aassr_v2 import build_full_aassr_core, build_pentest_aassr_core
```

The canonical integrated agent connects:

```text
observable state
-> shared semantic state
-> ASEQ
-> Policy + learned Skill candidates
-> Prophecy + transition-effect composition + Imagination
-> real primitive transition(s)
-> Knowledge Store
-> Prophecy/effect learning
-> feature memory
-> information-value learning
-> delayed Policy credit
-> GOAL completion
-> repeated successful ASeq -> Skill promotion
-> next real state
```

The historical component implementations remain available for reproduction, but the integrated constructor is the canonical 0.4 full-agent entry point.

### No double learning

The integration layer owns learning order explicitly. Real primitive transitions are learned by `AdvancedTransitionEvaluator`; the historical autonomous `observe()` learning path is disabled inside the integrated agent. The regression suite verifies that one real transition causes one base-Prophecy learning call.

### Reward boundary

The integrated core never changes the environment reward.

Pentest remains compatible with:

- proof success: `+1`,
- true lockout: `-1`,
- all other transitions: `0`.

Information value and GOAL scores are internal planning/credit signals, not injected environment rewards or correct-action labels. The default integrated GOAL is terminal success only.

### Knowledge, features, GOAL, Skill

Real transition facts are written to `KnowledgeStore` with trace provenance. Added facts are represented in `OnlineFeatureMemory`. Newly completed GOALs feed the existing `SkillLibrary`; repeated successful ASeq fragments can be promoted into Skill actions, and `SkillAwareProphecy` rolls their primitive effects in Imagination while reality still executes primitive actions one by one.

Detailed architecture: [`docs/aassr_v040_architecture.md`](../aassr_v040_architecture.md).

## Interpretation

The supported ASEQ mechanism remains narrow:

> observation-derived semantic equivalence plus suppression of repeatedly observed empirical `S -> A -> S` self-loops.

The result does not justify suppressing arbitrary repeated transitions.

ASEQ largely converts the previous failure mode from immediate semantic self-loop stalls into continued exploration. The higher truncation count in ASEQ arms shows that unresolved episodes can now continue until other limits rather than repeatedly selecting the same no-progress action.

The historical repetition filter removed `57,691` candidates across the three `original` cells, but removed `0` candidates in `original_plus_aseq`. This supports replacing the broad historical repetition scaffold with the narrower ASEQ self-loop mechanism.

The compound `learning_fix` condition did not improve development success in this experiment. Correct episode-boundary semantics should not be reverted merely for performance; its effect remains distinct from the now-resolved self-loop mechanism.

## Remaining bottleneck

ASEQ does not solve high-level transfer.

Combined successes by early diagnostic level were:

| level | original | original + ASEQ | learning fix | learning fix + ASEQ |
|---|---:|---:|---:|---:|
| L0 | 6/24 | 22/24 | 3/24 | 16/24 |
| L1 | 5/24 | 18/24 | 4/24 | 12/24 |
| L2 | 2/24 | 4/24 | 0/24 | 3/24 |
| L3 | 3/24 | 1/24 | 0/24 | 0/24 |
| L4+ | 0 | 0 | 0 | 0 |

The integrated full AASSR now exists against the audited semantic/observation contract, but its performance is not inferred from the DQN+ASEQ 2x2. The next full-system experiment must retrain and directly compare the integrated Policy/Prophecy/Imagination path on development data before any final blinded evaluation.
