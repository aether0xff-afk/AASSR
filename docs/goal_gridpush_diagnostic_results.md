# GOAL GridPush 진단 실험 결과

## 실험 조건

- seed: 7, 13, 21, 42, 100
- seed별 훈련: 40 episodes
- 훈련 맵: 8개
- 평가: 학습한 맵 10 episodes + 처음 보는 맵 10 episodes
- 외부 보상: 마지막 출구 도달 시에만 1
- 인위적인 tick 또는 energy 제한: 없음
- 실패: 지나간 칸을 다시 사용할 수 없는 환경에서 실제 가능한 행동이 사라진 경우
- 첫 Imagination 단계: 현재 가능한 모든 행동 비교

비교 조건:

1. Policy만 사용
2. Prophecy로 한 단계 비교
3. 여러 단계 Imagination
4. GOAL Maker와 GOAL Executor 분리

## 실제 행동 차이

학습한 맵의 episode당 평균:

- 여러 단계 Imagination: 행동 변경 3.04회
- GOAL: 행동 변경 4.44회, GOAL 생성 2.94회

처음 보는 맵의 episode당 평균:

- 여러 단계 Imagination: 행동 변경 0.66회
- GOAL: 행동 변경 3.00회, GOAL 생성 3.14회

따라서 이번 조건들은 이름만 다르고 같은 행동을 한 실험이 아니다.

## 해석

- 여러 단계 Imagination은 학습한 맵에서 모든 seed에서 Policy보다 높았다.
- 처음 보는 맵에서는 3개 seed에서 높고, 1개는 같고, 1개는 낮았다.
- GOAL 방식은 처음 보는 맵에서 평균 10%p 높았지만 seed별 변동이 크다.
- GOAL 방식은 학습한 맵에서 Policy와 거의 같았고 여러 단계 Imagination보다 낮았다.
- GOAL이 너무 자주 새로 만들어지고 행동도 자주 바뀌어 성공 경로가 길어지는 문제가 남아 있다.
- 현재 가장 강한 조건은 여러 단계 Imagination이다.
- 이 실험은 seed당 훈련 40회인 진단 규모이므로 최종 우위 증거가 아니라 확대 실험 후보를 고르는 결과다.
