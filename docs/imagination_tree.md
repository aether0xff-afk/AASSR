# 평행우주 Imagination 설계

## 목적

현재 상태에서 Policy가 높게 평가한 소수의 행동만 뿌리 후보로 선택하고, 각 행동 이후의 미래를 Prophecy가 예측한 상태로 이어 붙여 나무 형태의 평행우주를 만든다. 현실에서는 나무 전체를 실행하지 않고, 가장 높은 가치의 미래로 이어진 첫 행동 하나만 실행한다.

```text
현재 실제 상태
├─ 행동 A
│  ├─ 행동 A1
│  └─ 행동 A2
└─ 행동 B
   ├─ 행동 B1
   └─ 행동 B2
```

기본 분기 수는 `n=2`다. 최대 깊이 `k`는 고정 상한이지만, 실제로는 예측 신뢰도, 목표 달성, 반복 상태, 행동 부재에 의해 더 일찍 중단될 수 있다.

## 구현 원칙

1. Prophecy가 예측한 다음 상태를 해당 우주에서는 실제 상태처럼 사용한다.
2. 각 우주는 독립적인 임시 Policy 기억과 Prophecy 순환 기억을 가진다.
3. 신경망 가중치는 공유하되, GRU/LSTM의 은닉 상태는 우주마다 분리한다.
4. 상상 속 예측을 현실 자료로 취급해 Prophecy 본체를 다시 학습시키지 않는다.
5. 상상 종료 후 실제 Policy에는 뿌리 행동의 상대 가치만 반영한다.
6. 현실에서 얻은 다음 상태만 Prophecy의 학습 자료가 된다.

## 현재 코드

- `policy.py`: 전역 Policy 가중치와 우주별 `PolicyMemory`
- `prophecy.py`: 기존 예측 인터페이스와 선택적 순환 기억 인터페이스
- `imagination_tree.py`: 분기, 가지치기, 가치 집계, 뿌리 행동 강화
- `confidence.py`: 실제 예측 정확도에 따른 깊이 조절
- `evaluation.py`: 상상으로 첫 행동을 선택한 뒤 현실에서 한 번만 실행하는 폐루프

현재 구현은 Prophecy 종류에 독립적이다. 표 기반 Prophecy는 기존 `predict`를 사용하고, 이후 GRU/LSTM 구현은 `initial_memory`와 `predict_step`을 제공하면 우주별 은닉 상태를 사용할 수 있다.

## 우주 가치

기본 점수기는 다음 변화에 값을 준다.

- 최종 목표 진행도 증가
- 새 사실 획득
- 새 행동 활성화
- 행동 비용

환경에 별도 Reward 모델이 있다면 `ImaginationScorer`를 교체하여 같은 나무 구조를 유지한다. 각 경로의 값에는 누적 예측 신뢰도에 따른 불확실성 감점이 추가된다.

## 종료와 가지치기

한 가지는 다음 조건에서 종료된다.

- 최종 GOAL 달성
- 누적 예측 신뢰도 하락
- 다음 행동 부재
- 같은 상태 반복
- 최대 깊이 도달

각 깊이에서 생성된 모든 자식 중 보정 가치가 높은 `beam_width`개만 다음 깊이로 진행한다. 따라서 `n=2`를 유지하면서도 깊이에 따른 지수 폭발을 제한한다.

## 깊이 조절

`AdaptiveDepthController`는 실제로 실행한 행동의 Prophecy 정확도를 최근 구간에서 측정한다.

- 정확도가 여러 구간 연속으로 높을 때 깊이를 한 단계 증가
- 정확도가 낮아지면 깊이를 즉시 한 단계 감소
- 새로운 환경이나 미학습 상태에서는 얕은 상상으로 복귀

즉 Prophecy가 부정확할 때는 짧게 상상하고, 현실 경험으로 정확해질수록 더 멀리 상상한다.

## 현재 검증 항목

- 즉시 이득이 큰 막다른 행동보다 두 단계 뒤 목표를 달성하는 행동 선택
- 형제 우주 사이의 임시 Policy 기억 분리
- 실제 예측 정확도 상승에 따른 깊이 증가
- 미학습 예측에서 낮은 신뢰도로 즉시 중단
- 다음 행동이 없는 상태의 정상 종료
