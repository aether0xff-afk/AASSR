# Branch Critic 및 one-step Prophecy 5-seed 파일럿 결과

## 실험 목적

이 실험은 다음 두 질문을 분리해 확인했다.

1. 상상 트리에서 어떤 가지를 계속 확장할지 고를 때, 직전 변화만 보는 Critic과 가지 전체 흐름을 기억하는 GRU Critic 중 어느 쪽이 나은가?
2. 상상 모듈을 완전히 제외했을 때, Prophecy 모델별 한 단계 다음 상태 예측 정확도는 어떤가?

실험 seed는 `7, 13, 21, 42, 100`이다. 각 seed에서 학습 맵 8개와 처음 보는 맵 16개를 사용했다.

## 인간 개입 제한

Critic은 실제 에피소드의 최종 성공 또는 실패만 학습했다. 목표까지 남은 거리, 정답 행동 순서, 열쇠나 문의 중요도, 사람이 판단한 좋은 가지 점수는 학습에 사용하지 않았다.

Critic 학습에 성공과 실패 사례가 모두 필요했기 때문에, 최종 성공 보상만으로 학습한 DQN이 실제 환경에서 만든 행동 기록을 수집했다. 정답 경로나 Oracle 행동은 사용하지 않았다. 다만 이 데이터는 완전한 무작위 탐색이 아니라 목표를 학습한 행동 모델에서 나온 것이므로, 순수한 환경 이해 데이터라고 부를 수는 없다.

Prophecy는 실제 `(현재 상태, 행동, 다음 상태)`만 학습했다. 보상, 목표 거리, 행동의 좋고 나쁨은 입력하지 않았다. Prophecy 비교에서는 Policy와 Imagination을 사용하지 않았다.

Oracle Prophecy와 실제 최단 잔여 단계는 Critic의 가지 제거 결과를 검사할 때만 사용했고 학습에는 사용하지 않았다.

## Critic 결과

평균 ± seed 간 표준편차다.

| 조건 | 성공까지 도달한 맵 비율 | 성공 가능한 가지를 남긴 비율 | 중간 가지 성공/실패 순위 정확도 |
|---|---:|---:|---:|
| 현재 수동 점수식 | 0.150 ± 0.102 | 0.163 ± 0.094 | 해당 없음 |
| Parent Critic | 0.013 ± 0.025 | 0.088 ± 0.075 | 0.578 ± 0.197 |
| GRU Critic | 0.150 ± 0.116 | **0.250 ± 0.143** | **0.667 ± 0.219** |

`중간 가지 성공/실패 순위 정확도`는 성공으로 이어진 실제 가지가 실패로 이어진 가지보다 높은 점수를 받는 비율이다. 0.5면 무작위 순서와 비슷하다.

### 해석

Parent Critic은 현재 상태 변화 한 번만 보므로, 같은 변화라도 이전에 어떤 경로를 거쳤는지 구분하지 못했다. 최종 성공 도달률과 성공 가능한 가지 보존률 모두 낮았다.

GRU Critic은 가지의 이전 상태와 행동을 순서대로 기억했다. Parent Critic보다 실제 성공 경로를 더 잘 구분했고, beam 안에 성공 가능한 가지를 더 자주 남겼다.

그러나 GRU Critic의 최종 성공 도달률은 현재 수동 점수식과 같았다. 따라서 이번 파일럿만으로 수동 점수식을 GRU Critic으로 교체할 근거는 부족하다. 현재 확인된 것은 **가지 전체 흐름을 기억하는 방식이 직전 변화만 보는 방식보다 낫다**는 점까지다.

seed에 따른 차이도 크다. 처음 보는 맵에서 실제 행동 모델의 성공 에피소드 비율이 평균 1.8%에 불과해, Critic 검증용 성공 사례가 적었다. GRU Critic을 최종 채택하려면 성공과 실패가 더 균형 있게 포함된 실제 경험이 필요하다.

## Prophecy one-step 결과

처음 보는 맵에서 예측한 다음 상태가 숫자 상태, facts, 가능한 행동, 성공·실패 상태까지 모두 정확히 일치한 비율이다.

| Prophecy | 학습한 맵 완전 일치율 | 처음 보는 맵 완전 일치율 |
|---|---:|---:|
| Legacy GRU | 0.357 ± 0.029 | **0.000 ± 0.000** |
| Neural Delta | 0.672 ± 0.028 | **0.550 ± 0.062** |
| Transition-prefix | **0.825 ± 0.022** | **0.018 ± 0.033** |

### Legacy GRU

기존 GRU는 다음 숫자 상태를 출력한 뒤, 과거에 실제로 보았던 상태 중 가장 비슷한 상태를 골라 최종 예측으로 사용한다. 학습한 맵에서는 일부 상태를 다시 찾을 수 있었지만, 처음 보는 맵에서는 완전 일치가 한 번도 나오지 않았다.

처음 보는 맵의 숫자 상태 평균 오차도 `0.241 ± 0.014`로 가장 컸다. 따라서 문제는 과거 상태 선택 단계뿐 아니라 GRU의 숫자 예측 자체에도 있었다.

### Neural Delta

Neural Delta는 현재 상태 전체를 입력받아 다음 상태에서 변하는 양을 예측하고, 과거 실제 전이를 저장해 반복 학습한다. 처음 보는 맵에서도 완전한 다음 상태를 평균 55.0% 맞혔다.

숫자 핵심 상태만 보면 정확히 일치한 비율은 `0.789 ± 0.044`, facts까지 정확히 일치한 비율은 `0.593 ± 0.064`였다. 세 주 모델 중 처음 보는 맵 일반화가 가장 좋았다.

### Transition-prefix

이 모델은 `[현재 상태, 행동, 다음 상태]`를 하나의 학습 단위로 보고, `[현재 상태, 행동]`만 입력해 다음 상태를 맞혔다. 첫 구현에는 작은 Transformer를 사용했다.

학습한 맵에서는 82.5%로 가장 정확했지만 처음 보는 맵에서는 1.8%로 급락했다. 현재 구조는 공통된 환경 변화 규칙보다 학습 맵의 상태 조합을 외운 것으로 해석하는 것이 타당하다. Transformer를 더 크게 만드는 것은 현재 결과의 해결책으로 볼 근거가 없다.

## Neural Delta 성능 상승 원인

| 조건 | 처음 보는 맵 완전 일치율 |
|---|---:|
| Neural Delta 전체 | **0.550 ± 0.062** |
| 상태 변화량 대신 다음 상태 직접 예측 | 0.027 ± 0.037 |
| 과거 데이터 반복 학습 제거 | 0.285 ± 0.093 |
| 3개 모델 평균 대신 1개 모델 | 0.517 ± 0.064 |
| 사용된 칸 9개를 상태 표현에서 제거 | 0.000 ± 0.000 |

### 확인된 원인

가장 큰 차이는 **다음 상태 전체가 아니라 현재 상태에서 달라지는 부분을 예측한 것**이었다. 직접 다음 상태를 출력하게 하면 학습 맵에서는 맞았지만 처음 보는 맵에서 거의 전부 틀렸다.

두 번째로 큰 차이는 **과거 실제 전이를 저장하고 반복해서 다시 학습한 것**이었다. 반복 학습을 제거하면 처음 보는 맵 완전 일치율이 55.0%에서 28.5%로 내려갔다.

모델 세 개의 평균은 도움이 됐지만 영향은 작았다. 하나의 모델도 51.7%를 기록했으므로, 성능 상승의 주원인은 ensemble 자체가 아니다.

상태 표현에서 사용된 칸 9개를 빼면 숫자로 표시된 핵심 상태 16개는 평균 67.0% 맞혔지만, facts를 복원할 수 없어 전체 상태 완전 일치는 0%였다. 즉 Neural Delta의 성능에는 **더 완전한 상태 표현을 사람이 제공한 영향**도 포함되어 있다.

## 인간 개입 관점에서의 결론

Neural Delta는 목표나 정답 경로를 입력받지 않았으므로 보상 설계에 의한 직접 개입은 없다. 그러나 GridPush 상태를 25개의 숫자로 바꾸면서 사용된 칸 9개를 명시적으로 포함한 것은 사람이 정한 표현 방식이다. 이것은 이동 규칙이나 정답을 알려준 것은 아니지만, 어떤 정보를 보존해야 하는지 사람이 선택한 개입은 맞다.

따라서 현재 결과를 다음처럼 말해야 한다.

> Neural Delta의 일반화 성능은 변화량 예측과 실제 전이 반복 학습에서 주로 나왔으며, 완전한 상태 정보를 명시적으로 제공한 것도 중요한 역할을 했다.

“신경망만 바꿔서 성능이 올랐다”거나 “모델이 필요한 상태 표현까지 스스로 발견했다”고 말하면 안 된다.

## 현재 결정

- Parent Critic은 후속 주력 후보에서 제외한다.
- GRU Critic은 계속 실험할 가치가 있지만 현재 수동 점수식을 아직 대체하지 않는다.
- Prophecy의 현재 주력 후보는 Neural Delta다.
- Transition-prefix 방식은 아이디어와 구현은 보존하되, 현재 형태를 주력 후보로 사용하지 않는다.
- 다른 Critic 구조는 요청대로 아이디어 문서에만 남기고 구현하지 않는다.

## 남은 한계

reward-free 무작위 Prophecy 데이터에서는 성공 전이가 한 번도 나오지 않았다. 각 seed의 검사 데이터는 실패 전이 100개, 일반 전이 약 84~119개, 단계 변화 전이 약 9~21개로 구성됐다. 따라서 이번 one-step 결과는 일반 이동, 단계 변화, 실패 예측을 비교한 것이며 성공 전이 정확도는 아직 측정하지 못했다.

성공 전이를 일부러 만들어 넣으면 인간 개입이 커질 수 있다. 다음 검증에서는 Oracle 경로가 아니라 에이전트가 실제 문제 해결 중 자연스럽게 만든 성공 전이를 별도의 진단 데이터로 모아야 한다.
