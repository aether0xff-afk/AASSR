# 개발 계획

## 단계 0 — 새 기준점

- [x] 기존 코드와 분리된 새 파일 트리
- [x] 범용 행동과 상태 자료형
- [x] 출처가 있는 Knowledge Store
- [x] ASeq 전이 기록
- [x] Prophecy 인터페이스
- [x] Imagination 불확실성 측정
- [x] 정보 가치 계산 골격
- [x] 커리큘럼 단계 정의

## 단계 1 — 측정 가능한 최소 환경

- [x] 결정론적 GridWorld 어댑터
- [x] 고정 길이 상태 벡터 명세
- [x] 실제 ASeq 자동 기록
- [x] 단순 표 기반 Prophecy
- [x] 같은 상태-행동에 대한 다중 경험 예측
- [x] 한 전이에서 학습 전후 불확실성 및 예측 정확도 측정
- [ ] KK 갱신 효과와 Prophecy 파라미터 갱신 효과 분리
- [ ] 최근 전이 묶음 또는 검증 전이에서 예측 개선 측정
- [ ] 실행 로그 직렬화

현재 측정값은 최소 폐루프의 동작 검증용이다. 최신 전이를 다시 예측해 얻은 향상량을 최종 보상으로 사용하지 않는다.

완료 기준: 정책 보상을 바꾸지 않고도 모든 값이 로그에 일관되게 남으며, 학습에 사용하지 않은 전이에서도 예측 향상이 확인된다.

## 단계 2 — 정보 가치 학습

- [ ] 정보 가치 보상을 정책에 연결
- [ ] 정보 가치 예측기
- [ ] 새 행동 활성화 가치 계산
- [ ] 지연된 기여를 ASeq에 역배분
- [ ] 반복 및 오류 감점과 결합

완료 기준: 단순 새 정보 개수 보상보다 쓸모없는 정보 수집이 감소한다.

## 단계 3 — 커리큘럼

- [ ] 기본 이동과 관찰
- [ ] 벽이 있는 목표 도달
- [ ] 물체 획득 조건
- [ ] 문 상태 변화
- [ ] 열쇠-문 의존 관계
- [ ] 속성에 따른 관계 추론
- [ ] 처음 보는 복합 맵

완료 기준: 마지막 단계에서는 시범 없이 최종 목표만 제공한다.

## 단계 4 — 반례 환경

- [ ] 무작위 정보 발생기
- [ ] 목표와 무관한 풍부한 정보 구역
- [ ] 학습 가능한 불확실성과 학습 불가능한 무작위성 분리
- [ ] 새 물체 이름과 새 배치
- [ ] 더 긴 행동 의존 사슬

## 단계 5 — 확장

- [ ] 부수기, 설치하기, 조합하기를 포함한 샌드박스 환경
- [ ] 환경별 어댑터 규약
- [ ] 대규모 관측을 위한 선택적 임베딩
- [ ] Minecraft 계열 환경 연결 가능성 검토

마인크래프트의 사물별 제작법을 커리큘럼으로 직접 가르치는 것은 이 단계의 목표가 아니다. 범용 조작과 정보 가치 판단이 실제로 전이되는지를 먼저 검증한다.
