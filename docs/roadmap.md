## 단계 1 — 측정 가능한 최소 환경

- [x] 결정론적 GridWorld 어댑터
- [x] 고정 길이 상태 벡터 명세
- [x] 실제 ASeq 자동 기록
- [x] 단순 표 기반 Prophecy
- [x] 같은 상태-행동에 대한 다중 경험 예측
- [x] 한 전이에서 학습 전후 불확실성 및 예측 정확도 측정
- [ ] KK 갱신 효과와 Prophecy 파라미터 갱신 효과 분리
- [ ] 최근 전이 묶음 또는 검증 전이에서 예측 개선 측정
- [ ] 실행 로그 직렬화

현재 측정값은 최소 폐루프의 동작 검증용이다. 최신 전이를 다시 예측해 얻은 향상량을 최종 보상으로 사용하지 않는다.

완료 기준: 정책 보상을 바꾸지 않고도 모든 값이 로그에 일관되게 남으며, 학습에 사용하지 않은 전이에서도 예측 향상이 확인된다.

## 단계 1.5 — 평행우주 Imagination

- [x] Policy 상위 `n=2`개 행동으로 나무 분기
- [x] Prophecy 예측 상태를 다음 우주의 현재 상태로 사용
- [x] 우주별 임시 Policy 기억 분리
- [x] 순환형 Prophecy의 우주별 은닉 상태 인터페이스
- [x] 최대 깊이, 누적 신뢰도, 반복 상태에 따른 종료
- [x] Beam 가지치기
- [x] 잎 가치의 뿌리 행동별 역집계
- [x] 가장 좋은 뿌리 행동의 실제 Policy 가중치 강화
- [x] 실제 예측 정확도 기반 상상 깊이 증가·감소
- [x] 현실에서 첫 행동만 실행하고 다시 계획하는 폐루프
- [ ] 실제 경험으로 학습하는 GRU Prophecy
- [ ] GOAL 상태 차이 기반 잎 가치
- [ ] Skill 후보를 행동과 함께 상상
- [ ] 분기 수·깊이·집계 방식 기능 제거 실험

완료 기준: 즉시 이득이 큰 막다른 행동보다 여러 단계 뒤 최종 목표로 이어지는 첫 행동을 더 자주 선택하고, 상상 가치와 현실 결과가 양의 상관을 보인다.

마인크래프트의 사물별 제작법이나 특정 도구의 정답 옵션 조합을 커리큘럼으로 직접 가르치는 것은 목표가 아니다. 플러그인은 문법과 기본 조작만 제공하고, 어떤 조합이 목표에 유용한지는 에이전트가 경험으로 학습해야 한다.
