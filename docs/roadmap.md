## 별도 연구 검증 단계

구현 완료와 성능 주장은 구분한다. 다음은 코드 로드맵이 아니라 후속 실험 과제다.

- 여러 seed에서 상상 가치와 현실 결과의 상관계수 측정
- GRU와 표 기반 Prophecy의 데이터 효율 비교
- GOAL/Skill/군집/정보 가치 기능 제거 실험
- 무관한 정보가 풍부한 환경에서 쓸모없는 수집 감소 확인
- GridWorld에서 학습한 기능적 정보 역할이 Sandbox로 전이되는지 확인
- 실제 Minecraft 또는 승인된 실습망 transport를 연결하기 전 권한·중단·감사 로그 검토

플러그인은 문법과 기본 조작만 제공한다. 사물별 제작법, 특정 도구의 정답 옵션 조합, 목표까지의 행동 순서는 커리큘럼에 넣지 않는다.
