# AASSR v2 설계 기준

## 1. 연구 목표

AASSR v2는 사물별 정답이나 고정된 행동 순서를 배우는 에이전트가 아니라, 어떤 경험이 자신의 세계 예측을 개선하는지 측정하고 그 경험을 스스로 선택하는 에이전트를 목표로 한다.

사람이 제공하는 것은 다음뿐이다.

- 기본 조작 방식
- 행동이 상태를 바꿀 수 있다는 일반적 인과관계
- 정보와 물체가 새 행동을 가능하게 할 수 있다는 원리
- 여러 행동을 순서대로 조합할 수 있다는 원리
- 최종 목표

벽, 문, 열쇠, 색깔 같은 구체적 대상의 의미는 커리큘럼의 정답으로 고정하지 않는다.

## 2. 측정 대상

### 2.1 Imagination 불확실성

같은 상태와 같은 행동에 대해 생성된 여러 예상 다음 상태끼리 비교한다. 서로 다른 행동의 전략 다양성과 섞지 않는다.

```text
U(s, a) = 1 - 같은 (s, a) 예측들의 평균 코사인 유사도
```

KK 업데이트 전후의 차이는 다음과 같다.

```text
불확실성 감소 = U_before - U_after
```

### 2.2 Prophecy 예측 개선

Prophecy가 예측한 다음 상태와 실제 다음 틱 상태를 비교한다.

```text
예측 점수 = cos(predicted_next_state, actual_next_state)
예측 개선 = score_after_learning - score_before_learning
```

최신 전이 하나를 외우는 것을 막기 위해 예측 개선은 최근 전이 묶음이나 별도 검증 전이에서 측정한다.

### 2.3 정보 가치

```text
정보 가치
= 불확실성 감소
+ 예측 개선
+ 새로 열린 행동의 가치
+ 목표 진행도 증가
- 반복 감점
- 오류 감점
```

새 KK의 개수 자체는 보상 항목이 아니다.

## 3. ASeq 인과 연결

각 실제 전이는 다음 정보를 보존한다.

```text
행동 전 상태
→ 행동
→ 행동 전 다중 예측
→ 실제 다음 상태
→ 추가/변경/삭제된 KK
→ 새로 열린 행동
→ 목표 진행도 변화
```

각 KK는 자신을 만든 ASeq의 식별자를 저장한다. 나중에 어떤 KK가 어떤 행동을 열었고 어떤 목표 달성에 기여했는지 역추적한다.

## 4. 커리큘럼 원칙

1. 기본 이동과 관찰
2. 행동으로 인한 상태 변화
3. 정보 또는 물체가 행동을 가능하게 함
4. 여러 행동의 순차적 조합
5. 속성에 따른 관계 추론
6. 최종 목표만 주어진 처음 보는 복합 환경

커리큘럼은 해답을 외우게 하는 과정이 아니라, 정보의 가치를 판단하는 법을 배우게 하는 과정이다.

## 5. 구현 원칙

- 기존 AASSR 코드를 복사하지 않는다.
- 모든 보상 항은 원인을 추적할 수 있어야 한다.
- 측정 기능을 먼저 구현하고 정책 보상 연결은 나중에 한다.
- 상태 임베딩만으로 인과관계를 숨기지 않는다.
- 구체적 환경 요소와 범용 에이전트 코어를 분리한다.
