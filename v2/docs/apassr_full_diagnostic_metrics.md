# APASSR_FULL Diagnostic Metrics

This document defines the structural diagnostics added for `APASSR_FULL`.
Legacy C3/C5 use lightweight dependency lookahead, so full predicted-state
diagnostics are reported as zero for those conditions.

## Step Metrics

- `imagination_rollout_count`: number of imagined trajectories evaluated before
  one real action is selected. Numerator is trajectory count; denominator is one
  real step.
- `imagined_state_transition_count`: number of virtual state transitions
  generated before one real action.
- `imagined_trajectory_depth`: number of imagined steps in the selected
  trajectory.
- `future_candidate_count`: total candidates generated from imagined future
  states during the real step.
- `raw_future_candidate_count`: future candidate count before calibrated
  signature deduplication.
- `unique_future_candidate_count`: future candidate count after canonical
  signature deduplication.
- `duplicate_future_candidate_count`: raw minus unique future candidates.
- `future_candidate_dedup_ratio`: unique/raw future candidate ratio.
- `newly_unlocked_action_count`: candidates absent from the pre-transition
  imagined state and present after predicted delta-KK is applied. Identity uses
  template, WHAT, HOW, WHERE, and non-current-position binding signature.
- `raw_newly_unlocked_action_count`: newly unlocked candidates before canonical
  placeholder deduplication.
- `unique_newly_unlocked_action_count`: newly unlocked candidates after
  canonical placeholder deduplication.
- `unique_unlock_ratio`: unique/raw newly unlocked action ratio.
- `selected_action_has_future_dependency`: true when the selected trajectory
  unlocked at least one future action.
- `setup_action_selected`: true when the selected first action had lower
  immediate value than another candidate but won by rollout value and unlocked
  future actions.
- `selected_action_immediate_value`: first-step value of selected trajectory.
- `selected_action_future_value`: discounted value after the first imagined
  step.
- `mean_transition_confidence`: average Prophecy-derived transition confidence
  over imagined steps.
- `mean_selected_path_confidence`: average cumulative path confidence over the
  selected imagined trajectory.
- `mean_placeholder_grounding_factor`: average discount factor for selected
  placeholder or mixed-grounding transitions.
- `mean_selected_effective_confidence`: average transition confidence after
  grounding discount on the selected trajectory.
- `uncalibrated_selected_future_value`: selected future value before confidence
  discount.
- `calibrated_selected_future_value`: selected future value after confidence
  discount.
- `future_value_discount_ratio`: calibrated/uncalibrated selected future value.
- `placeholder_dependent_transition_count`: imagined transitions whose value
  depends only on placeholder/belief KVs.
- `mixed_grounding_transition_count`: imagined transitions combining concrete
  and placeholder/belief KVs.
- `concrete_transition_count`: imagined transitions with concrete grounding.
- `predicted_placeholder_kv_count`: placeholder/belief KVs generated by
  predicted delta-KK.
- `placeholder_generated_candidate_count`: future candidates whose bindings
  contain placeholder/belief KVs.
- `placeholder_execution_attempt_count`: executed real candidates containing
  placeholder/belief KVs. Expected to remain zero.

## Prophecy Alignment

KK predictions use `kk_prediction_threshold = 0.5`.

- `predicted_kk_precision`: true predicted KK / predicted KK.
- `predicted_kk_recall`: true predicted KK / actual semantic delta-KK.
- `predicted_kk_f1`: harmonic mean of precision and recall.
- `kk_brier_score`: mean squared probability error over all KK.
- `error_brier_score`, `flag_brier_score`: squared probability error for error
  and flag predictions.

## Imagined Action Match

When the selected imagined trajectory has a second action, the next real action
is compared against that predicted second action.

- `imagined_next_action_match`: exact diagnostic candidate signature match.
- `imagined_next_action_what_match`: WHAT axis match.
- `imagined_next_action_where_match`: WHERE axis match.
- `imagined_next_action_template_match`: template match.
- Samples with one-step trajectories are excluded from the match denominator.

## Episode And Summary Aggregates

Episode metrics sum counts and average rates over real steps. Summary metrics
average episode metrics over all seeds and episodes. Missing fields in older
CSV files are parsed as zero for backward compatibility.

## Calibrated Variant Metrics

`APASSR_FULL_CAL` uses the additional raw/unique and confidence fields above.
For C0-C5 and uncalibrated `APASSR_FULL`, the fields remain present in CSVs for
schema compatibility, but calibration-specific values are either zero or equal
to the uncalibrated rollout value depending on whether the full predicted-state
trace exists.
